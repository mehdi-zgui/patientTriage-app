# 🏥 Patient Triage System using AI

## 📌 Description
Ce projet est une application web développée dans le cadre du projet de fin de formation.  
Elle permet de **trier automatiquement les patients selon la gravité de leurs symptômes** en utilisant l’intelligence artificielle.

L’objectif principal est d’aider les professionnels de santé à **prioriser les cas urgents** et améliorer la qualité des soins.

---

## 🚀 Fonctionnalités principales

- 👨‍⚕️ Gestion des patients
- 🏥 Gestion du personnel (docteurs / infirmiers)
- 📋 Gestion des consultations
- 🩻 Gestion des radiographies
- 🤖 Prédiction de la gravité des cas via IA
- 📊 Historique des consultations

---

## 🧠 Intelligence Artificielle

- Modèle basé sur **Scikit-learn**
- Analyse des symptômes
- Classification des patients selon le niveau de gravité
- Aide à la prise de décision médicale

---

## 🛠️ Technologies utilisées

### Frontend
- React.js
- Material-UI

### Backend
- Flask (API REST)

### Base de données
- MySQL

### IA
- Scikit-learn (Machine Learning)

---

## 🏗️ Architecture

- Frontend : React
- Backend : Flask API
- Base de données : MySQL
- IA intégrée dans le backend

---

## 👥 Utilisateurs

- 👨‍⚕️ Docteur :
  - Gérer les traitements
  - Voir les historiques
  - Gérer les radiographies

- 👩‍⚕️ Infirmier :
  - Ajouter patients
  - Créer consultations
  - Lancer la prédiction IA
